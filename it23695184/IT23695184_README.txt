Singlish to Sinhala Transliteration Accuracy Testing
Project Overview


This project is part of the IT3040 - ITPM Assignment 1. The goal is to evaluate the accuracy of the "Chat Sinhala" transliteration function provided by PixelsSuite. This repository contains automated test scripts developed using Playwright to identify and document 50 scenarios where the system fails to correctly convert chat-style Singlish into Sinhala.

Prerequisites

Before running the scripts, ensure you have the following installed:

Python (Version 3.11 or 3.12 recommended)
Google Chrome or Chromium browser

Installation

Clone this repository to your local machine.
Open the terminal/command prompt in the project folder.
Install the required libraries using the following commands:
python -m pip install playwright openpyxl
python -m playwright install chromium


How to Run the Tests

To execute the automated test cases and generate results, run the following command in your terminal:
python test_automation.py --excel "Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --slow-mo-ms 200

Project Structure

test_automation.py: The main Playwright script for automation.
Assignment 1 - Test cases.xlsx: The Excel file containing 50 negative test cases.
